# LV3D Level Set Observations

Qualitative notes on level set geometry for each LV3D catalogue entry, observed via `level_set_animation_3d.jl`.

## LV3D_1

**Parameters:** `p_true = [0.50, -0.30, 0.20]`

Looks like two hyperplanes meeting — very anisotropic on this domain size. Possibly hyperbolic geometry (grows in all directions). A bit boring visually.

## LV3D_2

**Parameters:** `p_true = [0.80, -0.50, 0.30]`

Same as LV3D_1 — two hyperplanes meeting, very anisotropic, boring.

## LV3D_3

**Parameters:** `p_true = [0.30, -0.10, 0.40]`

Needs more points — hard to visualize, not enough density at default settings.

## LV3D_4

**Parameters:** `p_true = [0.60, -0.40, 0.25]`

Again almost like two hyperplanes (probably hyperbola) moving away; very flat. Hard to see at low density, but from a certain viewing angle the hyperbolic structure is visible.

## LV3D_5

**Parameters:** `p_true = [0.20, -0.60, 0.50]`

Two hyperplanes again. LV3D landscape geometry appears consistently hyperbolic across entries.

## LV3D_6

**Parameters:** `p_true = [0.60, -0.20, 0.60]`

Two hyperplanes, same as all previous entries.

## LV3D_7

**Parameters:** `p_true = [0.40, -0.80, 0.30]`

Two hyperplanes, same pattern.
