# Model Catalog

The complete catalogue of the 29 benchmark models — function names, parameter/state/output
counts, difficulty, system type, grouping by identifiability and observability, and the
recommended testing sequences — is maintained in the Globtim documentation, which is where
these objectives are consumed:

**→ [Model Catalog (Globtim docs)](https://gescholt.github.io/Globtim.jl/dev/model_catalog/)**

It lives in one place on purpose: the table is hand-maintained, and a second copy here
would drift from it.

Related pages there:

- [ODE Parameter Estimation](https://gescholt.github.io/Globtim.jl/dev/ode_parameter_estimation/) — overview, installation, distance metrics
- [Glued Objectives](https://gescholt.github.io/Globtim.jl/dev/glued_objectives/) — higher-dimensional problems with known critical-point sets

For the docstrings of the model-definition functions themselves, see the
[API Reference](api.md).
